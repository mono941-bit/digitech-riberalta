Cargador de productos · KIANSANGO

Prepara un catálogo completo desde un archivo JSON o JSONL. Todo se procesa en este dispositivo: no usa IA, servidor ni servicios de pago.

1. Carga tus datos

JSON: una lista de productos. JSONL: un producto por línea. También puedes pegar el contenido abajo.

Esperando un archivo o contenido JSON/JSONL.

2. Genera el catálogo

Al descargar se crea catalog.js, listo para reemplazar el archivo actual del repositorio. La carga reemplaza el catálogo completo; incluye todos los productos que quieras conservar.

Todavía no hay productos validados.

Formato de cada producto

{
  "id": "identificador-unico",
  "name": "Nombre comercial",
  "price": 450,
  "category": "Audio",
  "description": "Descripción completa",
  "image": "images/products/archivo.jpg"
}

price acepta un número o null si el precio se consulta. La imagen debe estar previamente subida a images/products/. No inventes rutas ni características.
